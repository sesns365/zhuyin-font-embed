# 內嵌注音字體小幫手（不能執行程式的 AI 版）

給 ChatGPT、Gemini 或不能執行 Python 的 Claude 使用。能執行程式時，請改用 `zhuyin-font-embed/SKILL.md` 與 `scripts/zhuyin.py`，效果較好（可離線、自動破音字詞庫、校對頁、Word）。

## 你的任務

老師要求「加注音」「注音版」時，產生字旁直接帶注音的 HTML，並自己判斷破音字讀音。

## 一、字型（線上載入）

在 `<head>` 加入：

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Bpmf+Zihi+Kai+Std&display=block">
<style>
body, body *:not(.no-bpmf) { font-family: 'Bpmf Zihi Kai Std', 'BiauKai', '標楷體', serif !important; }
body { font-size: 28px; line-height: 2.2; }
</style>
```

- 老師指定粉圓注音改 `Bpmf+Huninn` / `'Bpmf Huninn'`；芫荽注音改 `Bpmf+Iansui` / `'Bpmf Iansui'`。
- 這個方式需要網路才能顯示注音，請提醒老師。
- 標題等不要注音的元素加 `class="no-bpmf"`。

## 二、破音字

注音字型每個破音字有好幾個讀音，字後面加一個看不見的「選擇符」就能指定讀音：

| 寫法 | 意思 |
|---|---|
| `長`（不加） | 第 0 號讀音（預設） |
| `長&#xE01E1;` | 第 1 號讀音 |
| `長&#xE01E2;` | 第 2 號讀音 |
| `長&#xE01E0;` | 不標注音 |

各字的讀音順序查：https://raw.githubusercontent.com/sesns365/zhuyin-font-embed/main/zhuyin-font-embed/data/readings.json （字 → 讀音陣列，陣列位置就是編號）。

常用字的讀音編號：

| 字 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 長 | ㄔㄤˊ（很長） | ㄓㄤˇ（長大） | ㄓㄤˋ | |
| 行 | ㄒㄧㄥˊ（行走） | ㄏㄤˊ（銀行） | ㄒㄧㄥˋ（品行） | ㄏㄤˋ |
| 得 | ㄉㄜˊ（得到） | ˙ㄉㄜ（覺得、跑得快） | ㄉㄟˇ（你得去） | |
| 還 | ㄏㄞˊ（還有） | ㄏㄨㄢˊ（還書） | | |
| 著 | ˙ㄓㄜ（看著） | ㄓㄨˋ（著作） | ㄓㄠ（著急） | ㄓㄠˊ（睡著） |
| 地 | ㄉㄧˋ（土地） | ˙ㄉㄜ（慢慢地） | | |
| 了 | ˙ㄌㄜ（吃了） | ㄌㄧㄠˇ（了解） | | |
| 樂 | ㄌㄜˋ（快樂） | ㄩㄝˋ（音樂） | ㄧㄠˋ | |
| 為 | ㄨㄟˊ（成為） | ㄨㄟˋ（因為） | | |
| 重 | ㄓㄨㄥˋ（重要） | ㄔㄨㄥˊ（重新） | | |
| 種 | ㄓㄨㄥˇ（種子） | ㄓㄨㄥˋ（種樹） | | |
| 覺 | ㄐㄩㄝˊ（覺得） | ㄐㄧㄠˋ（睡覺） | | |
| 頭 | ㄊㄡˊ（頭髮） | ˙ㄊㄡ（石頭） | | |
| 相 | ㄒㄧㄤˋ（照相） | ㄒㄧㄤ（互相） | | |
| 數 | ㄕㄨˋ（數學） | ㄕㄨˇ（數一數） | | |
| 教 | ㄐㄧㄠˋ（教室） | ㄐㄧㄠ（教書） | | |

規則：

1. 逐句讀上下文，依教育部《重編國語辭典修訂本》判斷。
2. 「一」「不」預設標本調（ㄧ、ㄅㄨˋ），同國小課本，不加選擇符。
3. 交付時列出你調整過的破音字與拿不準的字，請老師確認。
4. 老師說「第 3 題的長要唸ㄓㄤˇ」時，只改那個字。
5. 老師也可以把文字貼到 https://buttaiwan.github.io/bpmfvs/ 校對後貼回給你，直接沿用貼回文字裡的選擇符。

## 三、輸出

- 完整單一 HTML（CSS、JS 內嵌），用 Canvas 或 Artifact 呈現；不能預覽時輸出完整程式碼區塊。
- 字級 24px 以上、行高 2 倍以上，注音字比一般字寬。
