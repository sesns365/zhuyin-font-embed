# 內嵌注音字體小幫手

把「字旁直接帶注音」的注音字型包進成品裡，並自動處理破音字。老師不用另外提醒破音字，本 skill 會：

1. 先用詞庫自動判斷（bpmfvs 詞庫 ＋ 特工365補充詞庫，國小常見詞）。
2. 詞庫判斷不了的字，由你（AI）逐句讀上下文決定讀音。
3. 真的拿不準的才列給老師確認，並附上可以點字換讀音的「破音字校對頁」。

## 預設值

| 項目 | 預設 | 其他選項 |
|---|---|---|
| 注音字型 | 字嗨注音標楷 `zihi` | 粉圓注音 `huninn`、芫荽注音 `iansui` |
| 「一」「不」 | 標本調（同國小課本，例如「一起」標ㄧ） | `--sandhi` 標變調 |
| 字型來源 | 只抽用到的字，內嵌進檔案（離線可用） | `--online` 改從 Google Fonts 載入（檔案小，要網路） |
| 範圍 | 整頁都有注音 | `--only ".passage, .question"` 只限部分區塊；個別元素加 `class="no-bpmf"` 排除 |
| 開關按鈕 | 右下角「注音：開／關」，列印時自動隱藏 | `--no-toggle` 不加 |

三套字型的讀音編號完全相同，換字型讀音不會跑掉。

## 環境

```bash
pip install fonttools brotli lxml
```

字型第一次使用時自動從 Google Fonts 官方 GitHub 下載並快取到 `~/.cache/zhuyin-font-embed/`（可用環境變數 `ZHUYIN_FONT_DIR` 改位置）。不能上網時用 `--font-file 字型檔.ttf` 指定本機檔案。

以下 `zhuyin.py` 指 `scripts/zhuyin.py`（以本 SKILL.md 所在資料夾為準）。

## 工作流程

### 步驟一：準備內容

- **老師給文字**：存成 .txt，第一行當標題，用 `text` 指令。
- **老師給 HTML**（或其他 skill 剛做好的網頁）：直接用 `html` 指令。
- **要你做新教材且要注音**：先照平常方式做好 HTML（字型照常寫，不用管注音），完成後再用 `html` 指令加注音。版面要預留空間：注音字比一般字寬約 1.4 倍，行高建議 2 倍以上，字級建議 24px 以上。
- **Word 檔**：用 `docx` 指令（見下方）。

```bash
python zhuyin.py html 學習單.html            # → 學習單_注音.html
python zhuyin.py text 課文.txt               # → 課文_注音.html
python zhuyin.py html 學習單.html --font huninn -o 學習單_粉圓.html
```

每次會產出三個附屬檔：

- `*_破音字報告.md`：給你看的報告（需判斷清單＋其他破音字）。
- `*_破音字報告.json`：同內容的 JSON。
- `*_破音字校對.html`：給老師用的校對頁。

### 步驟二：AI 判斷破音字（一定要做，不要跳過）

讀 `*_破音字報告.md`：

1. **「需判斷」表**：逐列讀上下文，判斷正確讀音。同一個詞多次出現會合併在同一列。目前讀音正確就不用動。讀音依教育部《重編國語辭典修訂本》，「一」「不」預設標本調。
2. **「其他破音字」表**：快速掃過，詞庫規則偶爾也會套錯（例如人名、新詞），看到錯的一起改。人名、地名請依該名字的慣用讀音。
3. 用 `fix` 一次改完（id 用逗號連接表示同一個讀音，-1 = 這個字不標注音）：

```bash
python zhuyin.py fix 學習單_注音.html --set "12,30,41=1 57=2 88=-1"
```

`fix` 會更新網頁、報告、校對頁。改完再看一次報告確認。

查某字有哪些讀音：`python zhuyin.py readings 長行和`

### 步驟三：交付

交付成品網頁與校對頁，回覆老師時簡短說明：

- 用了哪套字型、檔案多大。
- 破音字共幾個，AI 改了哪些（列幾個代表例子即可）。
- 仍拿不準的字（若有）列出來，請老師在校對頁確認。
- 校對頁的用法：點有虛線的字選讀音，按「下載修正後網頁」取代原檔；或按「複製修正碼給 AI」把修正碼貼回來。

PDF：`python zhuyin.py pdf 學習單_注音.html`（用 Edge／Chrome 無頭模式列印，字型會內嵌）。也可以請老師直接用瀏覽器開網頁 → 列印 → 另存為 PDF。

## 老師要改讀音時

| 老師的說法 | 做法 |
|---|---|
| 「第 3 題的『長』要唸ㄓㄤˇ」 | 在報告找到對應 id，`fix --set id=讀音編號`，只改那個字 |
| 貼回「破音字修正碼：12=2 30=1」 | `fix --set "12=2 30=1"` |
| 用 bpmfvs／toneoz 改好後貼回文字 | 文字存成 .txt，`python zhuyin.py merge 成品.html 修正文字.txt` |
| 想自己用 bpmfvs 改 | `python zhuyin.py export 成品.html` 產出純文字，請老師貼到 https://buttaiwan.github.io/bpmfvs/ |
| 「換成粉圓注音」 | `python zhuyin.py html 成品.html --font huninn -o 新檔.html`（已改好的讀音保留） |
| 「標題不要注音」 | 在該元素加 `class="no-bpmf"` 後重跑 `html`，或用 `--only` |

改一個字就只跑 `fix`，不要整份重做。

## Word

```bash
python zhuyin.py docx 學習單.docx            # → 學習單_注音.docx
python zhuyin.py docx 學習單.docx --set "5=1"  # 依報告 id 修正（從原始 Word 重新產生）
```

- 會把有中文的文字改成注音字型、插入破音字選擇符，並把字型（只含用到的字）內嵌進 .docx。
- 對方用 Windows／Mac 版 Word 開啟即可看到注音。Google 文件、手機 Word App 不支援內嵌字型，會看不到注音。
- 老師在 Word 裡新打的字若不在內嵌範圍，會顯示成其他字型；請老師安裝字型（Google Fonts 搜尋 Bpmf Zihi Kai Std）或重跑一次。
- Word 的步驟二同樣要做：讀報告、判斷、用 `--set` 從原始 Word 重新產生。

## 網頁裡用程式產生的文字（互動遊戲、動畫）

`html` 只處理寫在 HTML 裡的文字。報告開頭若提醒「程式碼（script）裡有 N 個中文字」，代表有文字是 JavaScript 產生的：

- 字型會照樣包含這些字（整份檔案的字都會抽進字型），只是破音字不會自動選讀音。
- 你自己寫的遊戲：破音字在字串裡直接加選擇符，例如 `"長\u{E01E1}大"`（讀音編號用 `readings` 查）。
- 程式若要比對文字（例如核對答案）或朗讀，先去掉選擇符：`s.replace(/[\u{E0100}-\u{E01EF}]/gu, "")`。

## 不要做的事

- 不要省略步驟二直接交付。
- 不要用 `--no-auto`，除非老師要求。
- 不要把字型檔另外附給學生或放進 repo；字型只在成品內嵌。
- 字嗨注音標楷不支援的罕用字會用備用字型顯示（沒有注音），報告不會列出；遇到請提醒老師。
